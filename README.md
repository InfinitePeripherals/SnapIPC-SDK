# SnapIPC SDK 1.0.0

This distribution contains the SDK, API documentation, and sample apps for adding an IPCMobile SnapHalo barcode scanner to an Android or iOS project. The public scanner client is named `SnapHalo`.

## What's included

| Folder | Contents |
| --- | --- |
| [Documentation](Documentation/) | Generated [Android](Documentation/Android/index.html) and [iOS](Documentation/iOS/index.html) API references for the SDK. Download the documentation folder and open each `index.html` locally to browse it. |
| [SDK](SDK/) | The [Android 1.0.0 AAR and Gradle metadata](SDK/Android/) and the [iOS XCFramework](SDK/iOS/) to add to your project. |
| [Samples](Samples/) | Working starting points for [Android / Kotlin](Samples/Kotlin/README.md), [iOS / Swift](Samples/Swift/README.md), and [React Native](Samples/ReactNative/README.md). Each sample README explains its setup and run steps. |
| [Wiki](wiki/Home.md) | Guides for getting started, pairing and connection, SDK usage, firmware updates, best practices, and troubleshooting. |

## Get started

1. Follow the [wiki quickstart](wiki/01-Quickstart.md) to choose a platform and add the matching SDK artifact.
2. Open the [Kotlin](Samples/Kotlin/README.md), [Swift](Samples/Swift/README.md), or [React Native](Samples/ReactNative/README.md) sample for a complete app and platform-specific instructions.
3. Use the [API documentation](Documentation/) while integrating, and return to the [wiki home](wiki/Home.md) for task-focused guidance.

Pairing and scanner features require a physical phone and SnapHalo scanner.

IBarcodeReader

interface IBarcodeReader

Barcode controls. Writes complete on BLE delivery, not firmware acknowledgement; failures throw. Queries use a fixed three-second timeout, including time waiting for other commands.

getSymobologies
Link copied to clipboard
abstract suspend fun getSymobologies(): Map<ScannerSymbology, Boolean>

Reads enabled states for all individually supported formats from the scanner. Excludes deprecated formats and control values such as All. Throws on query failure or timeout. Every call requests a fresh device-details snapshot; this does not use cached settings. Queries have a fixed three-second timeout, including time waiting for other commands.

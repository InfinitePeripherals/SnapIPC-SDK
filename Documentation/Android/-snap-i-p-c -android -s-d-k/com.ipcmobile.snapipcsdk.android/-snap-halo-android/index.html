SnapHaloAndroid

@MainThread
class SnapHaloAndroid : AutoCloseable

Activity-bound NFC and Bluetooth permission integration for Android.

Create exactly one instance in ComponentActivity.onCreate, after super.onCreate and before STARTED. It handles the launch intent, subsequent intents, and NFC reader mode automatically. Required runtime permissions are requested on first start and on a later explicit retry or valid NFC tap. Connections wait for permission and Bluetooth-enable results. Firmware uploads use the connected scanner and are canceled when this adapter closes. Pending permission work survives Activity recreation; in-progress BLE connections do not.

All public methods must run on the main thread. Lifecycle destruction calls close automatically. The scanner remains owned by the host. Hosts still declare their Activity intent filters.
